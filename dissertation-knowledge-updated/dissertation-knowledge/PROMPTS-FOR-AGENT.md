# Промпты для Claude Code агента

## 🚀 Первый запуск - Инициализация Knowledge Base

Скопируй и выполни в Claude Code:

```
Привет! Я работаю над диссертацией "Research on Security Tools using Golang for Penetration Testing". 

В папке dissertation-knowledge/ находится knowledge base для синхронизации между сессиями. 

Твои задачи:
1. Прочитай все файлы в dissertation-knowledge/
2. Проанализируй текущий код проекта и обнови PROGRESS.md:
   - Какова структура проекта?
   - Какие модули уже реализованы?
   - Какие Go-библиотеки используются?
   - Что работает, что нет?
3. Обнови TOOLS-ANALYSIS.md с архитектурой проекта

После анализа дай краткий отчёт что нашёл.
```

---

## 📊 При каждой новой сессии

```
Прочитай dissertation-knowledge/ и продолжим работу над проектом. 
Что было сделано в прошлый раз согласно PROGRESS.md?
```

---

## 🔧 После завершения работы

```
Обнови knowledge base:
1. Добавь в PROGRESS.md что было сделано сегодня
2. Если менялась архитектура - обнови TOOLS-ANALYSIS.md
3. Если есть заметки для теории - добавь в RESEARCH-NOTES.md
```

---

## 📝 Для документирования кода (для приложений диссертации)

```
Создай/обнови CODE-DOCS.md с документацией кода:
- Описание каждого модуля
- Примеры использования
- Комментарии к ключевым функциям
Это пойдёт в раздел "Приложения" диссертации.
```

---

## ❓ Для получения информации для теории

```
Мне нужна информация для теоретической части диссертации по теме: [тема]
Добавь найденную информацию в RESEARCH-NOTES.md с источниками.
```
